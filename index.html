The Windows desktop client for LibreNMS

Getting started

Up and running in a minute

No agents, no server-side install — DashyNMS talks straight to the LibreNMS API you already have.

1

Install

Grab the installer from Releases and run it. No admin rights required — it installs just for your Windows account.

2

Sign in

Enter your LibreNMS server address and an API token from Settings → API → API Access. Encrypted for your account, never sent anywhere else.

3

Leave it running

Closing the window sends DashyNMS to the tray, not the exit. It keeps polling and notifies you when something changes.

Everything at a glance, laid out your way

A drag-and-resize grid of widgets — arrange it once and it stays that way between sessions.

  • Live alerts and an alerts-at-a-glance gauge, updated on your polling interval.
  • Device status counts, pinned sensor readings, and a graph of any device's own metrics.
  • Recently viewed and pinned devices, so the ones you check on most are always one click away.
  • Health at a glance — dBm, signal, temperature and fan speed, colour-coded against your LibreNMS limits.

A device grid built for real fleets

Sort, filter and act on your devices without a browser tab open next to it.

  • Pin your important devices to keep them at the top regardless of sort or filter, with columns you choose from the header.
  • Multi-select bulk actions — pin, unpin, add to a group, or rediscover several devices at once.
  • Add devices without leaving the app — SNMP v1/v2c/v3 or ping-only, with the same safety options LibreNMS's own API offers.
  • A full Device View for anything — sensors, ports with LLDP/CDP neighbours, CPU/memory/disk, VLANs, MAC/ARP tables, graphs and a searchable event log.

Alerts you can act on, rules you can trust

Everything goes through LibreNMS's own API — nothing is duplicated or reinterpreted.

  • Filter by severity and state with one click, search across host/rule/note, and export the current view to CSV.
  • Acknowledge with a note, or put an alert back to active.
  • A full alert-rule editor that mirrors LibreNMS's own — nested AND/OR condition groups, import from another rule or a pasted SQL query, and see how many alerts each rule has raised.
  • Alert templates — list, create and edit what a notification actually says, and which rules drive it.

Notifications that fit how you work

One shared poller in the tray — quiet until there's something to say.

  • Per-severity control over how insistent a toast is — fade away, stay until dismissed, or stay with a repeating sound.
  • Quiet hours and start-up suppression keep it from being noisy on a machine you actually work on.
  • The tray icon shows your worst outstanding severity and how many alerts are open, without opening the window.
  • Closing the window docks to the tray instead of quitting — it keeps polling in the background.
And the rest

Built to fit into how you already work

Groups and locations, a settings window for everything, and a straightforward story about where your data lives.

Groups and locations

Browse and filter by LibreNMS's own device groups and locations, with the same click-through into Device View you get from the grid.

One settings window

Connection details and polling interval, alert display and health thresholds, per-severity notification behaviour, device-list defaults, window behaviour, and appearance — theme, accent, even your server's own logo.

Your data stays yours

Everything lives under %APPDATA%\DashyNMS — your server address, settings and encrypted API token. Nothing is sent anywhere except the LibreNMS server you signed in to. Delete the folder and it's gone.

Requirements

Windows 10, build 17763 (version 1809) or later, and a LibreNMS instance with the API enabled — plus a token from Settings → API → API Access.
