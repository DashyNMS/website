Getting started

What you need: Windows 10 (version 1809 or later) or Windows 11, and a LibreNMS server you can reach from your computer, with its API turned on.

Creating a token: in LibreNMS, go to your user menu, then API → API Settings → Create API access token. If you don’t have access, ask your LibreNMS administrator.

Signing in: open DashyNMS, enter the server address (for example https://librenms.example.net) and paste the token. No server to hand? Choose Try the demo on the sign-in window to look around an example network.

Common questions

“It says it can’t reach my server.”

Check you can open the server’s address in a browser on the same computer. If it’s only reachable on your office network, connect to the VPN first.

“My server uses a self-signed certificate.”

Turn on “Allow untrusted certificate” when signing in. DashyNMS asks before trusting a certificate the normal checks reject, then accepts only that one. Only do this for a server you run yourself.

“I closed the window but it’s still running.”

That’s on purpose: closing the window sends DashyNMS to the notification area so it can keep watching for alerts. Right-click the tray icon and choose Exit to quit.

“I’m not getting notifications.”

Check notifications are allowed for DashyNMS in Windows Settings, that Focus or Do Not Disturb isn’t on, and that quiet hours aren’t set in DashyNMS’s own Settings.

“Can I have it start when Windows starts?”

Yes. Turn on Start with Windows in Settings.

“How do I remove it completely?”

Uninstall it from Windows Settings → Apps, then delete %APPDATA%\DashyNMS to remove your settings and saved token.

“Do I need DashyNMS Mobile too?”

No. Desktop works on its own with any LibreNMS server. DashyNMS Mobile is there if you want alerts on your phone as well.
