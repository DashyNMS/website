DashyNMS Mobile support

Stuck, or found a bug? Here’s how to get help.

Getting started

What you need: a LibreNMS server you can reach from your phone (over your network or a VPN) and an API token.

Creating a token: in LibreNMS, go to your user menu, then API → API Settings → Create API access token. If you don’t have access, ask your LibreNMS administrator.

Signing in: enter the server address (for example https://librenms.example.net) and paste the token.

Common questions

“It says it can’t reach my server.”

Check you can open the server’s address in your phone’s browser. If it’s only reachable on your office network, connect to the VPN first.

“My server uses a self-signed certificate.”

Turn on “Allow untrusted certificate” when signing in. Only do this for a server you run yourself.

“I’m not getting notifications.”

Check notifications are allowed for DashyNMS in your phone’s settings, and that alert notifications are on in the app’s Settings. The app checks for new alerts in the background, as often as your phone allows, so a notification can take a few minutes to arrive.

“The widgets are empty.”

Open the app once after installing so it can run its first alert check.

“Can I use it without DashyNMS desktop?”

Yes. The app works on its own with any LibreNMS server.
