# Accessibility

The DashyNMS website supports desktop and mobile browsers. We have not completed
a formal accessibility audit and make no WCAG conformance claim.

Report a barrier through the [website issue form](https://github.com/DashyNMS/website/issues/new?template=bug_report.yml&labels=accessibility).
Include the page, browser, device and assistive technology, and describe what
you were trying to do. Email [dashynms@pckp.net](mailto:dashynms@pckp.net) if a
public report is unsuitable. The maintainer reviews these reports.
