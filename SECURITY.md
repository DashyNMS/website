# Security policy

Report vulnerabilities in the live DashyNMS website or its publishing workflows
through [GitHub private vulnerability reporting](https://github.com/DashyNMS/website/security/advisories/new).
Include the affected page or revision, the impact and enough detail to reproduce
the problem with synthetic data. The maintainer aims to acknowledge reports
within five working days.

Please give the maintainer time to fix the problem before sharing details.
Security fixes apply to the website published from `main`. For a problem in a
DashyNMS app or package, use the reporting link for the
[affected repository](https://github.com/DashyNMS/.github/blob/main/SECURITY.md).
